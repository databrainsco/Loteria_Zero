# Screenshots

Catalog screenshots must be captured with **qFlipper** and committed unchanged.

Requirements (Flipper Apps Catalog):

- PNG
- Exactly **512 x 256**
- Landscape
- Only orange `(254, 138, 44)` and black `(0, 0, 0)`
- No editing, cropping, recoloring, or AI images

Suggested captures:

1. Main menu
2. Game card view
3. History
4. Settings
5. Our story / About
